# Dependency Analysis Skill

## Purpose
Map structural and runtime dependencies in an existing system.

## Analyze
- project references
- package dependencies
- layer dependencies
- shared libraries
- infrastructure dependencies
- circular dependencies
- coupling hotspots

## Output
Prefer `docs/reverse-engineering/01-dependency-map.md` and Mermaid diagrams when useful.

## Guardrails
Do not treat naming conventions alone as proof of architectural boundaries.
