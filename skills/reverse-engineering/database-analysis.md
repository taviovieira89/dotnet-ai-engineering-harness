# Database Analysis Skill

## Purpose
Recover the data-access and persistence architecture of a legacy system.

## Analyze
- database technology
- ORM or direct SQL usage
- repositories and data-access abstractions
- stored procedures
- transactions
- caching
- schema ownership where inferable
- persistence coupling

## Output
Prefer `docs/reverse-engineering/05-data-architecture.md`.

## Guardrails
Never output connection strings, credentials, hosts, account names, or production data.
