# Integration Analysis Skill

## Purpose
Discover and document external and internal integration boundaries.

## Analyze
- REST
- SOAP
- messaging and queues
- file-based integrations
- scheduled jobs
- SDK clients
- internal services
- external services

For each integration capture:
- direction
- protocol
- responsibility
- coupling
- failure behavior when identifiable

## Output
Prefer `docs/reverse-engineering/06-integrations.md`.

## Guardrails
Do not publish private URLs, tokens, credentials, tenant IDs, subscription IDs, or proprietary payload data.
